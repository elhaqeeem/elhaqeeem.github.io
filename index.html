Panduan Mendaftarkan Redirect URI di Google Cloud Console

Berikut adalah langkah-langkah untuk mendaftarkan Redirect URI untuk aplikasi Anda di Google Cloud Console:

1. Masuk ke Google Cloud Console

  • Buka Google Cloud Console.
  • Masuk dengan akun Google yang memiliki akses ke proyek Anda.

2. Arahkan ke Bagian API & Layanan

  • Di panel navigasi sebelah kiri, pilih API & Layanan.
  • Klik Kredensial.

3. Temukan Kredensial OAuth

  • Temukan kredensial OAuth 2.0 yang telah Anda buat untuk aplikasi Anda. Biasanya, ini berupa Client ID dan Client Secret.

4. Edit Kredensial

  • Klik pada nama kredensial OAuth yang ingin Anda edit.
  • Di halaman detail kredensial, cari bagian URI Pengalihan (Redirect URIs).

5. Tambahkan Redirect URI yang Valid

  • Klik tombol Tambahkan URI Pengalihan (Add Redirect URI).
  • Masukkan URL https://elhaqeeem.github.io/callback (atau URL lain yang sesuai jika Anda memiliki path spesifik).
  • Pastikan untuk menambahkan URL yang dapat diakses publik dan bukan localhost.

6. Simpan Perubahan

  • Setelah menambahkan URI pengalihan, jangan lupa untuk menyimpan perubahan.

Dengan mengikuti langkah-langkah di atas, Anda dapat mendaftarkan Redirect URI yang valid untuk aplikasi Anda di Google Cloud Console.
